---
title: Interacting with AWS
---

Every action we make in AWS is an API call that is authenticated and authorized.

API calls can be made in several ways, the most used ones being:

- the AWS Management Console
- the AWS Command Line Interface
- the AWS Software Development Kits

## AWS Management Console

It is a web-based console to manage cloud resources.
